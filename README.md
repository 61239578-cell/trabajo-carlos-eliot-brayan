# ZUMO — Tienda web profesional

Sitio estático multipágina en español, adaptable a móviles y escritorio.

## Páginas
- `index.html`: portada de marca
- `tienda/index.html`: catálogo con búsqueda y filtros
- `producto/zumo/index.html`: ficha de producto y selector de cantidad
- `como-jugar/index.html`: guía de preparación de partida
- `nosotros/index.html`: propuesta de marca
- `blog/index.html`: ideas editoriales
- `preguntas-frecuentes/index.html`: preguntas frecuentes
- `contacto/index.html`: formulario de consulta

## Precio y producto
El Excel comercial proporcionado registra el producto `JUEGO ZUMO` a **S/ 35.00** por unidad. El sitio no inventa otros productos ni especificaciones no confirmadas.

## Configuración antes de publicar
Edita `assets/config.js` y configura el WhatsApp y/o correo oficial de ZUMO. Los campos `WHATSAPP` y `EMAIL` están vacíos intencionalmente; no se reutiliza el contacto de la tienda anterior. La bolsa de compras funciona en el navegador y conserva su selección localmente, pero no hay pasarela de pago, base de datos ni panel de administración.

## Imágenes
Coloca las imágenes generadas en `assets/img/` con estos nombres: `zumo-hero.webp`, `zumo-producto.webp`, `zumo-componentes.webp` (opcional) y `zumo-familia.webp` (opcional). Mientras tanto, se muestran composiciones gráficas provisionales.

## Publicación
Sube todos los archivos y carpetas a un hosting estático que mantenga las rutas relativas. Para pruebas locales, usa una extensión/servidor local (por ejemplo Live Server), no abras solamente una subpágina aislada.
